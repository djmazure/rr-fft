# FFT-P2.8 verification

The structural contract declares the two input AXI-stream bundles, the output bundle, aclk, active-low aresetn, and aclken. Existing behavioral requirements remain unchanged.

FFT-REQ-030 now has separate scaled and unscaled cocotb witnesses. Both load committed fixtures minted by `rr sim golden mint` from the existing fixed-point oracle. Each case resets, configures the transform, sends a constant complex 256-sample frame and the data-pushed flush, requires a complete output frame, checks sample indices, and compares the first complex result with the oracle.

The 516 scaled vectors retain four original cases and add every four-pair schedule in {0,1,2,3}^4 in each transform direction, using signed odd amplitudes to exercise truncation and wrap. Six unscaled vectors retain the original cases and add both directions with asymmetric signed values and input extremes. Unscaled mode has no runtime scaling schedule; its oracle vectors use zeros. This is exhaustive schedule coverage, not exhaustive input-amplitude or transform correctness. DC does not cover non-unity twiddle multiplication; existing FFT-REQ-001/002 witnesses remain necessary.

FFT-REQ-021 retains its original sign-extension, index, liveness, and full-frame value assertions. Its fixture now includes the 256 oracle-generated inverse-frame components; the test compares every raw 80-bit output against their minted sign-extension result. The original standalone packing vectors are retained before those frame cases. The frame oracle goldens remain generated by model/gen_golden.py; the packing seam adds independently traceable fixture provenance without replacing the transform checks.

## Negative controls

On 2026-09-10, an isolated source copy replaced the core reorder data output connection with `open` and tied only m_axis_data_tdata to zero; valid/index signaling was preserved. Both unchanged DC tests failed at case 0 with FFT-REQ-030 value mismatch assertions. The correct RTL passed both tests. No test assertion was weakened and no production RTL was changed. No new DUT defect was found: the observed defects were missing declarations and a missing witness, tracked by FFT-P2.8. Attacks included zero output, every scale schedule, signed truncation, and unscaled input extremes; this does not substitute for future arbitrary-frame adversarial work.
